OSM Mapper Handleiding

Inleiding

Deze Java-applicatie voegt markers toe aan een OpenStreetMap-kaart.

Hoofdmenu

Algemene weergave

  • Kaarten uit vorige sessies worden geladen.
  • Anders wordt een leeg middenvenster getoond.
  • Onderaan verschijnen status- en foutmeldingen.

Voeg GEO-info toe

Verrijkt een Excel-bestand met latitude en longitude per adres. Maximaal één aanvraag per seconde (Nominatim OpenStreetMap).

Input XLSX-bestand

Selecteer het invoerbestand.

Output XLSX-bestand

Selecteer het uitvoerbestand.

Nieuwe kaart

Maakt een nieuw kaarttabblad aan.

XLSX-bestand selecteren

  • XLSX-bestand
  • Titel
  • Projecten (optioneel filter)
  • Fotomap

Lege kaart aanmaken

Nieuwe kaart gecentreerd op Utrecht.

Wissel kaart

Wisselen via menu of tabblad.

Mail voorbereiden

Mailing applicatie wordt gestart, waarbij de gekozen kaart als input wordt gebruikt.

Kaartinformatie

  • Rechtermuisknop slepen = verplaatsen
  • Muiswiel = zoomen
  • Hover = popup
  • Klik = details

Marker-detailvenster

  • Titel: huisnummer
  • Beschrijving: adres
  • Details: contactgegevens
  • Latitude en longitude

Als er foto's beschibaar zijn, dan wordt de knop "Toon Foto's (aantal) getoond.

Excel-informatie

In de uitvoer Excel worden de kolommen: "long", "lat" and "land" gecreeerd / overschreven.

Adresvelden

  • postcode
  • huisnummer
  • toevoeg
  • straat
  • plaats
  • land (optioneel)

Contactvelden

  • voornaam
  • achternaam
  • telefoon
  • e-mail

Overige velden

  • project
  • kleur
    De kleur van de marker kan worden ingesteld. Indien niet opgegeven, wordt er random een kleur gekozen ("RED", "BLUE", "GREEN", "ORANGE", "MAGENTA").

    De volgende kleuren kunnen worden opgegeven (in Engels):
    "AQUA", "BLACK", "BLUE", "CYAN", "DARKGRAY", "DARKGREY", "DARK_GRAY", "FUCHSIA", "GRAY", "GREEN", "GREY", "LIGHTGRAY", "LIGHTGREY", "LIGHT_GRAY", "LIME", "MAGENTA", "MAROON", "NAVY", "OLIVE", "ORANGE", "PINK", "PURPLE", "RED", "SLATEGREY", "TEAL", "WHITE", "YELLOW"

  • lat
  • long
