Introductie

Het doel van deze (java) application is om markers op een (OSM-) kaart te tonen.
De marker informatie is afkomstig uit een Excel-sheet.

De eerste tab van een Excel Werkboek wordt ingelezen.

Wat is nieuw:
- Java upgrade naar versie 25.
- Module/intgratie tests (JUnit 5) zijn toegevoegd (nog niet volledig).
- De code is op sommige punten geherangschikt.
- De afhankelijkheden met andere pakketen is aangepast naar de nieuwste versies.
